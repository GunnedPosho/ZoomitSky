# ZoomitSky

A Minecraft Fabric mod that implements a normal zoom and a cinematic zoom with multiple modes and customizable settings. Perfect for exploration, content creators, and players looking for an enhanced visual experience.

## Features

**Two Zoom Modes**
- **Normal Zoom (Z):** Clean and fast zoom without visual distractions.
- **Cinematic Zoom (C):** Includes cinematic black bars and hides the interface for professional shots.

**Two Control Styles**
- **Hold Down:** Hold the key to zoom (classic mode).
- **Press Once:** Press to activate/deactivate zoom (ideal for long shots).
- Switch between modes with a single key (customizable from keyboard settings).

**Adjustable Zoom with Scroll**
Use the mouse wheel to dynamically adjust the zoom level while zooming.

**Adaptive Sensitivity**
Mouse sensitivity is automatically reduced with zoom to improve control and precision even at maximum zoom.

**Reset Zoom**
Resets the zoom level to default values with a single key.

**In-Game Configuration**
Adjust zoom behavior directly from the Mod Menu config screen — no need to edit files manually.

## Controls

| Action | Default Key |
|---|---|
| Normal Zoom | Z |
| Cinematic Zoom | C |
| Toggle Control Style | V |
| Reset Zoom | (unbound) |

All keys are fully configurable from the in-game keyboard settings.

## Dependencies

- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Mod Menu](https://modrinth.com/mod/modmenu) *(required for config screen)*
- [Cloth Config](https://modrinth.com/mod/cloth-config) *(required for config screen)*

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/installer/) for Minecraft 1.21.1
2. Download and install the dependencies listed above
3. Place the ZoomitSky `.jar` in your `mods/` folder
